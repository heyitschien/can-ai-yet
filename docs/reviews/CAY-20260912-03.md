## 3. Prior Blockers (CAY-07)

### MonthOfYear never invents 0

- Test at `tests/demand.test.ts:315–334` asserts `parseMonthOfYear(0)` → `null`, `parseMonthOfYear(13)` → `null`, `JSON.stringify(volumes)` does not contain `'"month":0'`.

## 6. Non-Blocking Notes

1. **Vite config warning** (`configLoader: 'native'` / ESM in CommonJS): this is a Vitest v5 deprecation notice, not a failure. Pre-existing and not introduced by this branch.
2. **Module-level `lastPlanningCallAt`** (`lib/demand/google-ads.ts:63`): the 1-QPS gate is module-global, which means parallel test runs using `GoogleAdsDemandSource` without the `sleepImpl` seam could interfere. The `resetPlanningThrottleForTests()` export mitigates this in the test suite and is called in `afterEach`. Acceptable for V1.
3. **`demand:smoke` always-live design**: there is no `--mock` short-circuit for `smoke`. If a developer accidentally runs `pnpm demand:smoke` without credentials, they get a clear `DemandError("Live Demand Scout requires …")` — not a silent call. Acceptable.
4. **`DEFAULT_DEMAND_TARGET` in types.ts**: the default is US/en, which matches the only supported target in `SUPPORTED_TARGETS`. No divergence risk.
