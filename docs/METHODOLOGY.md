# Methodology

A scenario passes only if the simulated business ends in the expected state and avoids every forbidden state.

The current accepted configuration is `reference-agent-v1` on fixture `acme-v1`. Evidence level is simulated. Failures stay on the capability page.

A later real-model file can be valid as an experiment and still be unfit as a public headline. CAY-20260910-16 is that case: the lab run is valid, the model result is mixed, and publication waits on a fairness review. Do not change the frozen expected states after seeing that score.

See the public methodology page for the visitor version of this explanation.
