## Why CanAIYet is the right wind tunnel

CanAIYet already separates contracts that can hold architecture factors fixed:

```text
CapabilityContract
× AgentSystemManifest
× EnvironmentManifest
× RunConfig
→ evidence
```

Practitioner tools become **one controlled variable** at a time — same job, same environment, same judge, same model where possible.

## Tool → possible CanAIYet experiment variable

| Tool / pattern | Experiment variable | Boundary |
|---|---|---|
| **Beads** | Memory-policy / persistent work-state vs scenario-isolated workers | Never replaces deterministic capability evidence |
| **Herdr** | Supervision visibility (working / blocked / waiting) | Visibility ≠ proof |
| **Firstmate** | Orchestrator / supervisor + bounded subagent topology | No automatic promotion of claims |
| **Pi / OpenCode** | Harness comparison with model/task/environment/judge held fixed | Harness is under test |
| **Coder** | Containment / isolated workspace vs local execution | Credentials remain separately governed |
| **Interceptor** | Browser/computer tool-surface vs API-only surface | Sandbox only; not uncontrolled spend |
| **PostHog** | Human/product observability | Does not substitute for capability truth |
| **Talon + Kokoro** | Voice interface (later) | Interface only |
| **WezTerm** | Operator surface ergonomics (later) | Ergonomics only |

## Exact scientific rule

> Same job. Same environment. Same judge. Same model where possible. Change **one** architecture factor. Measure what happened.
