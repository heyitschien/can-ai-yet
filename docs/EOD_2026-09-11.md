> **The current simulator is a wind tunnel, not the destination.**

The validation ladder is:

```text
1. deterministic synthetic wind tunnel       ✅ demonstrated
2. real software sandbox + synthetic data    ← next technical falsification
3. customer staging/sandbox environment      ← only if Level 2 transfers + demand exists
4. production-derived private regressions    ← only if customers pull us there
```

Internal company evals and CanAIYet are not assumed to be substitutes. The stronger hypothesis is that CanAIYet can provide standardized capability packs, independent evidence, reusable failure/scenario knowledge, longitudinal history, and eventually tests that run inside the customer's own staging environment.

The possible moat is therefore **not** simply "we can run an eval." Generic eval execution will likely commoditize.

Potential compounding assets include:

- realistic scenario/failure corpus;
- task-first capability definitions;
- failure taxonomy + severity evidence;
- portable scenario contracts;
- standardized comparability;
- safe-permission/delegation envelopes;
- longitudinal accepted evidence;
- practitioner/customer-derived regression cases;
- trust/independence if earned.
