## Strategy decisions preserved tonight

See:

- `docs/DECISION_RECORD_2026-09-11.md`

Key decisions:

1. The strongest current product abstraction is **safe delegation boundaries**, not generic model intelligence.
2. A future capability report should include the **minimum safe permission envelope** where evidence supports it.
3. Google Ads Demand Scout should be interpreted as **commercial search pull**, not as a complete measurement of enterprise delegation demand.
4. Finish Demand Scout V1, make one clean smoke call, inspect real rows, then **freeze expansion** until evidence justifies more engineering.
5. Do not immediately build embeddings/HDBSCAN/LLM clustering, scheduling, Supabase demand storage, or autonomous demand→benchmark execution.
6. Evaluation science must separate **within-scenario stochastic variance** from **between-scenario generalization**.
7. Failure **type** and **severity** should be separate dimensions.
8. Future benchmark versions should consider untrusted-input/prompt-injection and temporal/path-dependent work, without modifying the existing frozen Sonnet evidence.
9. A small number of additional current model-family runs can be used as **benchmark instrument calibration**, not as premature leaderboard marketing.
10. The reviewed Sonnet run should become the first public evidence artifact before large benchmark/demand infrastructure expansion.
