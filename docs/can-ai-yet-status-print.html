The one-sentence story

We built Can AI Yet, a public website that lists everyday business chores and says whether a tested helper can do them. Visitors can search, read a result, and ask for a new test. The house is built and the lights are on at https://canaiyet.com.

2

What is real

Live

The public site

Home, search, capability pages, method, updates, and a request form. Someone can type “follow up with sales leads” and get a real match.

Live

The name on the door

canaiyet.com points at the site. The padlock works. www sends people to the main address. Link previews use a branded Can AI Yet card. A yellow note in Vercel only asks for a newer address. The current one still works.

Real run

The 10 report cards

Each score came from a run. Nothing was invented to look good. The site says the evidence is a simulation.

Saved

The filing cabinet

The public results live in a database. Strangers cannot rewrite them. The request form can add a request without opening the private drawer.

What the scores really mean

We did not pay ChatGPT, Claude, or Gemini to take these tests. A small practice robot walked through a fake company called Acme and we graded what it did. Cost so far: $0.

Green means the practice robot passed every case, with only light watching. Yellow means it missed some, so a person should still check the work. No score was copied from a marketing page.

What is pretend, on purpose

  • The office is fake. Emails, customers, invoices, and calendars are practice props, not your real business.
  • The helper is a reference agent. It is a stand-in, not a frontier model.
  • Search matches words. It does not use the smarter “meaning” search yet.
  • Spreadsheet tests use simple tables in memory, not real Excel files.
